# To-Do List

# Функционал
*   **Добавление, редактирование и удаление задач.**
*   **Отметка выполнения**.
*   **Поиск** по названию задачи.
*   **Фильтрация** по статусу выполнения.
*   **Сортировка** по дате.
*   **Drag-and-Drop** — изменение порядка задач перетаскиванием мыши.
*   **Сохранение данных** в `localStorage`.

## Техническая реализация
*   **Чистый JavaScript с использованием DOM API.**.
*   **Динамическое создание интерфейса:** HTML-файл содержит только базовый каркас. Все элементы создаются через `document.createElement` и вставляются через `append`.
*   **Архитектура:** Данные хранятся в массиве объектов. Изменение интерфейса происходит через функцию `renderTasks()`, которая перерисовывает список на основе актуального состояния массива.
*   **Адаптивность:** Реализована через CSS  для корректного отображения на мобильных устройствах.
